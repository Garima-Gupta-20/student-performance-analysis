# Student Performance Analysis

This project analyzes student marks using Python and Excel.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MS Excel

## Objective
To analyze subject-wise performance and visualize score distribution.

## Visualizations
- Box Plot
- Bar Chart
- Summary Statistics

## Outcome
Identified performance trends across different subjects.
